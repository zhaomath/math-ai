# 小学数学AI助教 · 使用说明

一款面向**小学 1–6 年级**数学教学的网页应用，覆盖**课堂互动、作业批改、学情分析、个性化辅导**四大场景，含**教师端 / 学生端 / 家长端**三端协同闭环。纯前端实现（HTML+CSS+原生JS），数据存于浏览器本地，无需服务器即可运行。

## 一、如何打开
- **方式一（推荐）**：用支持本地服务器的浏览器打开（已内置预览地址）。
- **方式二**：直接双击 `index.html` 即可在浏览器中运行（localStorage 在 `file://` 下同样可用）。
- 若需多人/多设备共享数据，可把本目录部署到任意静态服务器或后续接入后端。

## 三、功能概览
### 教师端（橙色）
- **班级管理**：批量导入学生（姓名,手机号,学号,家长手机号），自动创建并绑定家长账号。
- **AI 作业批改**：选择作业与学生 → 上传作答图片 → AI 模拟识别各题 → 标注错误位置与类型 → 教师可手动修正 → 一键发布成绩（自动加积分、同步错题本）。
- **题库管理**：AI 联网生成 / 按苏教版知识点添加 / 手动创建；按年级与知识点分类；一键发布「分层作业 / 课堂练习」。
- **学情分析**：班级与学生成绩、积分、高频错误知识点、AI 教学建议、个人报告。

### 学生端（浅蓝）
- **课堂/课后练习**：作答已发布作业，提交后即时反馈；「AI 随堂小测」实时答题、即时反馈、答对加分。
- **积分激励**：答对得分，积分可视化并持久化。
- **错题本**：错误原因标注 + 同类变式题推送 + AI 语音讲解（Web Speech 中文播报）。
- **学习报告**：个人成绩、积分、错题与趋势。

### 家长端（浅绿）
- **学习报告**：查看孩子作业、成绩、积分，支持「下载/打印」（打印样式已优化）。
- **错题同步**：同步孩子错题本，可标注「辅导重点」。
- **AI 家庭辅导建议**：根据错题类型生成可操作的居家辅导建议，可打印。

## 四、通用能力
- 手机号+密码**注册 / 登录 / 密码重置 / 账号注销**（账号设置内）。
- 三端**数据打通**：教师发布作业 → 学生作答/错题 → 家长同步查看，形成协同闭环。
- 响应式布局，适配**手机 / 平板 / 电脑**（侧边栏在手机端变为抽屉+底部标签栏）。

## 五、关于「AI」
当前版本内置**可替换的模拟 AI 引擎**（`js/ai.js`），用于离线演示完整工作流：
- 批改判定、错误类型识别（计算/单位/审题/概念错误）、同类变式生成、讲解与建议文本、学情统计、语音播报均已实现。
- 真实部署时，可将 `ai.js` 中的 `gradeQuestion / recognize / genByKP / explain / suggest` 等函数替换为调用大模型 / OCR / TTS 接口，其余 UI 与数据流无需改动。

## 六、数据持久化
所有数据存于浏览器 `localStorage`（键 `mathai_db_v1`、`mathai_session_v1`）。清除浏览器数据会重置演示库；生产环境建议接入后端数据库。
